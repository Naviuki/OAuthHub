# OAuthHub — Единый центр аутентификации

## 1. Описание проекта

**OAuthHub** — веб-приложение на ASP.NET Core 8 для аутентификации пользователей через внешних OAuth-провайдеров (Google, Яндекс, ВКонтакте) и локальную регистрацию. Приложение предоставляет:

- Регистрацию и вход по Email/паролю
- Вход через Google, Яндекс, MailRu
- Привязку/отвязку нескольких OAuth-провайдеров к одному аккаунту
- Управление профилем (смена пароля, удаление аккаунта)
- Управление активными сессиями (просмотр, завершение)
- Двухфакторную аутентификацию (вкл/выкл)
- Экспорт данных пользователя в JSON и CSV
- Страницу подтверждения опасных действий
